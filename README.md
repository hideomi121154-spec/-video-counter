# Video Counter

YouTubeを見ながら、その下の空きスペースでカウントできるiPhone向けWebアプリ/PWAです。

## MVP 0.1

- YouTube URL / 動画IDを入力してアプリ内再生
- 動画とカウンターの境界をドラッグして高さ調整
- MODE A〜Fを独立保存
- GAME +1 / -1
- 5種類のカウンター +1 / -1
- GAME数に対する出現率 `1/○○` を自動計算
- 打ち始めGm / 総Gm / 個人Gm
- 試行回数 / 突入回数 / 突入率
- MODE単位のリセットと全データ削除に確認ダイアログ
- localStorageによる自動保存・再起動復元
- PWAアプリシェルのオフラインキャッシュ
- iPhoneを含むレスポンシブ対応
- 対応端末ではVibration APIによるベストエフォート触覚フィードバック

## 重要: iPhoneの触覚について

Web/PWAからの振動はiOS/Safariの対応状況に依存します。画面上の押下アニメーションは常に動作しますが、確実なiPhoneハプティックが必要な場合は将来のネイティブ版（Swift / UIKit / SwiftUI）で `UIImpactFeedbackGenerator` 等を使用します。

## 安全設計

- YouTube IDは許可したYouTube URL形式から抽出し、iframeのURLへ直接任意文字列を入れません。
- 埋め込みは `youtube-nocookie.com` を使用します。
- 保存データは読込時に非負整数へ正規化し、壊れた保存データは安全な初期値へ戻します。
- リセット/全削除は確認後のみ実行します。
- Service WorkerはYouTube/動画配信トラフィックをキャッシュしません。
- ユーザーデータはサーバー送信せず、このMVPでは端末のlocalStorage内だけに保存します。

## 手動テスト

1. YouTube URLを貼り「表示」で再生できる。
2. 赤/緑/黄/青/白を複数回押し、回数が正しく増える。
3. GAMEを増やすと各 `1/○○` が再計算される。
4. 各 `−1` とGAME `−` が0未満にならない。
5. MODE Aで記録後、MODE Bへ移動し別データを作り、Aへ戻るとAの値が残る。
6. ページを再読込して全状態が復元される。
7. 境界バーを上下ドラッグして動画領域が24〜70%程度の範囲内で変わる。
8. MODEリセットで選択MODEのみ0になる。
9. 全データ削除でA〜F・補助計算・動画URLが消える。
10. 不正なYouTube URLではiframeを生成せず入力エラーになる。
